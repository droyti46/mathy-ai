## Инструкция по запуску

Клонируйте репозиторий:

```bash
git clone https://github.com/droyti46/mathy-ai.git
```

### Запуск backend:

1. Перейдите в директорию с бэкендом

    ```bash
    cd backend
    ```

### Запуск frontend:

1. Перейдите в директорию с фронтендом

    ```bash
    cd frontend
    ```
